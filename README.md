# Stock Portfolio Tracker

## Project Description
Stock Portfolio Tracker is a Python-based application used to calculate the total investment value of a stock portfolio.

## Features
- Displays predefined stock prices.
- Accepts stock names from users.
- Gets the quantity of stocks.
- Calculates individual stock investments.
- Calculates total portfolio investment.

## Technologies Used
- Python
- Dictionary
- Loops
- Conditional Statements
- User Input

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Run `python stock.py`.
